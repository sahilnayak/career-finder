---
description: Browser web comb for fresh roles matching your target roles in your area (last 24h, list only)
---

Comb the open web with real browsers for roles matching `targets.roles` in config/profile.yml, posted in the last
24 hours in the configured `location`, and return a ranked list of 10.

Load the career-finder skill:
```
skill({ name: "career-finder" })
```
